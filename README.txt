GRL FARMS - HTML/CSS/JavaScript Website

No React, no Vite, no npm required.

To run:
1. Extract the ZIP.
2. Double-click index.html, OR open it with VS Code Live Server.
3. Replace placeholders in index.html:
   PHONE_NUMBER
   WHATSAPP_NUMBER
   EMAIL_ADDRESS
   FARM_LOCATION
4. Replace the Unsplash image URLs with your real farm photographs.

Main files:
- index.html
- style.css
- script.js

The site includes:
- Responsive premium homepage
- Sticky navbar + mobile menu
- Farm story
- Farm sections
- Crops
- Gallery + lightbox
- Visit section
- Contact CTA
- Scroll reveal animations
